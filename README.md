# 🏥 CrossCare Hub v3.5 - Professional Master

**「医療事務の算定は、もっと楽しく学べるはずだ。」**

そんな想いから生まれた、超実践型・医療事務ラーニングシミュレーターです。

## 🌟 プロジェクトの概要

医療事務の現場で最も重要かつ複雑な「点数算定」。
従来の座学だけでは身につきにくい判断力とスピードを、**150名の豪華有名人ゲスト**による仮想症例を通じて、ゲーム感覚でマスターすることができます。

## 🚀 本バージョンの目玉

### 1. 豪華150名の「VIP患者」が来院！

佐藤健様から明石家さんま様まで、誰もが知る有名人たちが患者として登場。

「あの人が膝の注射に来た時の算定は…？」と、印象に残りやすい学習体験を提供します。

### 2. 令和6年（2024年）診療報酬改定に完全対応

「生活習慣病管理料II」や「リフィル処方箋」など、最新のルールに基づいた算定ロジックを搭載しています。

### 3. 全症例に「医療事務トリビア（豆知識）」を搭載

算定をクリアすると、その項目に関連した**実務で役立つ裏話やコツ**が表示されます。

- 「レントゲンは実は『影』を見ている？」
  
- 「手術当日の再診料が取れない理由とは？」
  
- 「湿布薬の70枚制限のナゾ」
  など、明日から職場で話したくなる知識が満載です。
  

## 🛠 搭載ジャンル

1. **外来算定**: 初診・再診・時間外など基本のキ
  
2. **画像・検査**: 複雑なまるめ（包括）算定の攻略
  
3. **投薬・管理**: 指導料や長期処方の加算マスター
  
4. **時間外・特例**: 深夜・休日・救急搬送の緊迫シーン
  
5. **手術・処置**: 面積計算や手術当日ルールの徹底演習
  

## 💻 使い方

1. `index.html` をブラウザで開きます。
  
2. サイドバーからジャンルを選択。
  
3. 症例を選び、適切な項目を「Add（追加）」または「Check（確認）」していきます。
  
4. 正しい点数に到達し、ミッションコンプリートを目指しましょう！
