# CrossCare Hub v3.2 - Professional Master

150人の著名人（シナリオ）と共に学ぶ、医療事務・算定シミュレーターの決定版。

## 特徴

- **150の豊富な症例**: 外来、検査、投薬、時間外、手術・処置の全5ジャンル。
- **PWA対応**: スマホのホーム画面に追加して、オフラインでも学習可能。
- **1行データ設計**: メンテナンス性に優れた軽量・高速動作。

## 使い方

1. リポジトリをクローンまたはダウンロード
2. `index.html`をブラウザで開く、またはGitHub Pagesで公開
3. モバイル端末のブラウザで開き「ホーム画面に追加」
